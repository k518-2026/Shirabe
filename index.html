Shirabe について

ブラウザーの中だけで動く統計解析ソフトです。データはどこにも送信されません。

  • すべての計算はこのソフト独自の JavaScript 実装です。主な結果は Python の SciPy・statsmodels と突き合わせて確かめています。
  • 統計の計算はどれも完璧ではありません。大事な分析では、R・JASP などほかのソフトでも結果を確かめてください。
  • Shirabe は JASP を参考にした操作感を目指していますが、JASP のソースコード・画像・データは一切使っていない独立したソフトです。JASP チームやアムステルダム大学とは関係がありません。JASP はアムステルダム大学の商標です。
